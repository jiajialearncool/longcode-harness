# 同一模型下的四组编码评测

日期：2026-10-07。本次比较 LongCode Harness 完整版、Codex、OpenCode、Pi 在同一道自拟中等难度编码题上的实际完成情况、耗时与 Token 用量。四组均使用 `gpt-6.1-sol`、`xhigh` 和同一个 ChatGPT 订阅账户；LongCode、OpenCode、Pi 分别完成自己的官方 OAuth，Codex 使用已有登录。通过账户邮箱指纹核对账户一致，没有复制其他工具的凭据，没有使用 OpenAI API Key 或 Claude 服务。

耗时从启动对应程序开始，到程序结束为止，包含其读取、编码、自行测试与框架检查，不包含随后进行的外部隐藏验收。四组有效运行合计 **1,448,791 Token**。

## 题目、验收和停止条件

题目是补全一个已有的 Python / SQLite 库存工具：实现批量预留、请求幂等、释放、到期回收、持久化和命令行接口。要求处理输入归一化与校验、事务失败回滚、旧库存数据保留、多实例并发不超卖，以及 JSON 输出与退出码。这是本次评测自拟的题目，没有借用公开题库的难度或成绩。

四组从字节一致的起始项目开始，收到相同用户提示、README 契约和 7 项基础公开测试。只能使用 Python 标准库，只能修改 inventory/、tests/、README.md；不联网查题、不安装依赖、不启动子 Agent、不提交或推送。各程序保留自己的系统提示和工具循环。

每组最多运行 **90 分钟**，不设 Token 硬上限。程序自然结束或达到墙钟时限后停止；中途公开测试失败不会触发外部停止。过程中没有追加人工提示，也没有向一组提供另一组的答案。

外部隐藏验收有 28 个测试方法，部分方法包含多个边界子例。验收覆盖业务状态、请求幂等、失败原子性、输入边界、持久化、旧库兼容、并发和 CLI。参考实现通过全部验收，初始未实现项目未通过。隐藏验收仅在程序停止后运行，其结果没有回传给被评测程序。

按种子 20261007 固定生成的顺序为 OpenCode → LongCode → Pi → Codex，依次运行。起始文件、隐藏验收和实际 LongCode 源文件保存了 SHA256；结束后核对未变化。

## 额外预检和无效运行

评测接入配置曾出现两次错误，对应运行被取消并保留记录。这些不是编码能力失败，不计入正式成绩。

| 项目 | 已观察耗时 | 已返回 Token | 原因及处理 |
| --- | --- | ---: | --- |
| 首次 OpenCode 无效运行 | 492.697 秒 | 374,027 | 外层隔离阻止读取祖先目录元信息，SQLite 无法打开数据库；修正权限后，从冻结项目重跑。 |
| 首次 LongCode 无效运行 | 658.401 秒 | 495,707 | macOS 拒绝嵌套命令隔离；恢复产品自身隔离及检查程序后，从冻结项目重跑。 |
| 模型和命令工具预检 | 各请求独立记录 | 54,335 | 四组最小真实模型请求，以及修正后的 Codex SQLite 命令请求。 |

两次无效运行共观察到 **869,734 Token**；加上预检，正式成绩之外共 **924,069 Token**。取消时尚未返回的响应没有暴露用量，因此额外消费的精确总量不可知。有效运行、无效运行及预检合计可观测 **2,372,860 Token**，不包含负责组织评测的聊天用量和未返回用量的中断响应。

macOS 不支持重复应用命令隔离。LongCode 使用产品自身的文件范围限制、命令隔离和检查程序；其余三组使用评测程序的外层隔离，Codex 关闭重复的内层隔离。隐藏答案读取、范围外写入和 SQLite 命令均做过实际检查。

前面的无效运行可能预热服务端缓存，本次没有清空或控制服务端缓存。执行顺序、服务端波动、各程序的上下文和工具实现均可能影响耗时与 Token，不能将结果解释为统一冷启动。
